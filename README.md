# Data supporting the study of future vegetation changes in the Brière marshes (France)

## Overview

This repository contains the data supporting the scientific article investigating potential changes in vegetation patterns in the Brière marshes (Loire-Atlantique, France) by 2100 under climate change.

The study aims to identify the main environmental factors influencing vegetation dynamics and to assess potential changes in natural habitats under contrasting environmental and management scenarios.

Two contrasting vegetation trajectories are considered:
- Maintenance of a freshwater marsh ecosystem.
- Transition towards a brackish marsh ecosystem.

## Study area

The study focuses on the Brière marshes, a coastal wetland located in Loire-Atlantique, western France.

## Data description

The repository contains five Excel files providing the datasets used to support the analyses and results presented in the scientific article.

The files include:

| File name | Description |
|---|---|
| `Indicator_values_Tichy_et_al 2022-11-29.xlsx` | Indicator values from Tichy et al. (2022). |
| `indicesALADIN63_CNRM-CM5_...xlsx` | Climate index data from the ALADIN63-CNRM-CM5 model. |
| `mean_indicesALADIN63_CNRM-CM5_...xlsx` | Mean climate index values from the ALADIN63-CNRM-CM5 model. |
| `mean_reference_indicesALADIN63_CNRM-CM5_...xlsx` | Mean reference climate index values from the ALADIN63-CNRM-CM5 model. |
| `ombrothermic diagram.xlsx` | Ombrothermic diagram data. |

All datasets are provided in Microsoft Excel (.xlsx) format.

## Temporal framework

The study compares the current situation (2023) with potential vegetation changes by 2100.

## Data format

All datasets are provided in Microsoft Excel (.xlsx) format.

## Data availability

All data supporting the findings of this study are available in this repository.

## Reproducibility

These datasets are provided to ensure transparency and facilitate the assessment and reuse of the data supporting the scientific results presented in the article.
